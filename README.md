# 🎟️ EventVerse - Event & Hackathon Booking Platform

A full-stack MERN application for booking events and hackathons. Includes Admin tracking and User collections.

## Tech Stack
- **Frontend:** React, Vite, Axios, CSS
- **Backend:** Node.js, Express, MongoDB, JWT Auth

## How to Run the Project
1. Open two terminals.
2. In the first terminal, start the backend:
   ```bash
   cd Server
   npm install
   node index.js
3. In the second terminal, start the frontend:
   cd Client
   npm install
   npm run dev
